2. How did this activity affect your motivation to do similar kinds of work in the future?
3. What value do you see in connecting technical or computing work with human, ethical, or societal considerations?

## Response

This activity made me think more about the connection between programming and practical robotics. Writing the movement pattern is not only about getting the Python syntax correct. I also had to think about coordinate frames, velocity, distance, turning radius, timing, and how the commands would affect a robot in the real world.

One thing that stood out to me was the difference between passing software tests and proving that something that works in the real world. My pattern could satisfy the mathematical and code requirements while live ROS requirements could still remain incomplete. That made me realize how important testing and safety are in robotics.

The activity also boosted my interest in robotics and computing because it combined programming with physical motion and problem solving. I liked being able to take a specification, translate it into code, create tests, find an error, fix it, and review the result.

I saw how important it is in considering human and societal factors. A robot cannot operate alone, so safety, accessibility, pedestrians, and shared spaces matter in addition to whether the code fulfill all requirements. Overall, the activity showed me that good robotic programming requires both correct implementation and careful study of how a system behaves in the real world.
